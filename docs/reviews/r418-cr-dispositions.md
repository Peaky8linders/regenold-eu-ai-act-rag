# R418 — deep code review of the R411–R417 diff: findings and dispositions

**Scope.** `e23e766^..HEAD` (the last five merged PRs: #424 `f658a49`, #427 `04aa6c9`,
#428 `b27419b`, #429 `94bdbdc`, plus the R417/R418 work in this branch), reviewed by
ten specialist agents — five lenses (`logic`, `errors`, `contract`, `concurrency`,
`security`) × two partitions (production `app/`, plus `evals/`+`tests/`) — dispatched
by `scripts/deep_code_review.py` per `CR-SKILL.md`. Raw agent reports:
`docs/reviews/cr-r416/*.md`.

Every disposition below is grounded in a code read, a measurement run in this round, or
both; none is accepted on a reviewer's word alone. Where a fix changes a graded path it
is measured on the repo's own surfaces before it ships, and one finding is **refuted** by
measurement rather than implemented.

**The round's most important result is a falsification.** The first fix attempted here
(agent-demanded `has_prior_turns=True`, fix 2) *caused* a regression on the deterministic
eval surface the moment it landed without its companion: 8/255 `in_scope_multi_turn`
negative scenarios went from answered to refused. It was caught by running
`tests/test_regenold_scope.py::TestRegenoldEvalGate` against a clean **HEAD worktree** and
diffing the per-scenario outcome, not by reading the diff. Both halves of the fix are now
in, and the surface is back to HEAD's exact result (253/255, the same two pre-existing
`off_topic_regulation` failures).
