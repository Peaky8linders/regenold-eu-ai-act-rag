## Important Issues

### [I1] Reference Contract Leakage and Alias Score Splitting in RRF Fusion
- **File:** [`app/engines/hybrid_rrf_retriever.py:30-110`](file:///d:/Claude%20Projects/regenold-eu-ai-act-rag/app/engines/hybrid_rrf_retriever.py#L30-L110)
- **Bug:** Un-anchored regex matched prose strings, and un-canonicalized reference aliases (`Art. 13` vs `Article 13`) across BM25 and vector lists split RRF scores into separate buckets.
- **Impact:** Emitted illegal `"Art. 13"` wire citations violating `AGENTS.md` Invariant 1 and degraded candidate fusion ranking.
- **Suggested fix:** Add `canonicalize_article_ref` (`Art. N` -> `Article N`), enforce end-of-string bounds with `_REF_VALID_RE`, and canonicalize all items before RRF score aggregation.
- **Confidence:** High (95%)
- **Found by:** Logic, Correctness & Legal Grounding Reviewer; Error Handling Reviewer
- **Status:** **FIXED & VERIFIED**

### [I2] Over-capturing Compliance Questions into Simple Definition Class 0
- **File:** [`app/engines/query_complexity_router.py:24-38`](file:///d:/Claude%20Projects/regenold-eu-ai-act-rag/app/engines/query_complexity_router.py#L24-L38)
- **Bug:** `_DEFINITION_QUERY_RE` matched any query starting with `"What is..."`, classifying short substantive obligation questions (e.g. `"What is required for high-risk AI?"`) into Class 0 (Simple definition).
- **Impact:** Under-retrieved retrieval context ($k=3$) for substantive compliance questions.
- **Suggested fix:** Refine `_DEFINITION_QUERY_RE` with negative lookahead `(?!required|the\s+penalty|obligations?|requirements?)`, support trailing `.`/`!`, and exclude Article 5.
- **Confidence:** High (95%)
- **Found by:** Logic Reviewer; Error Handling Reviewer
- **Status:** **FIXED & VERIFIED**

### [I3] Cache Key Identity Mismatch for HyPA & Extended Complexity Flags
- **File:** [`app/routes/regenold.py:1239-1250`](file:///d:/Claude%20Projects/regenold-eu-ai-act-rag/app/routes/regenold.py#L1239-L1250)
- **Bug:** Default-ON flags evaluated to `""` in `_engine_cache_key` when unset, but `"1"` when explicitly passed, causing false cache misses. `REGENOLD_COMPLEX_GATE_WIDE` was omitted.
- **Impact:** Cache key poisoning across pairwise A/B judge arms.
- **Suggested fix:** Use `int(is_adaptive_router_enabled())` and `int(is_rrf_retrieval_enabled())` and register `REGENOLD_COMPLEX_GATE_WIDE`.
- **Confidence:** High (88%)
- **Found by:** Contract & Integration Reviewer
- **Status:** **FIXED & VERIFIED**

### [I4] RRF Boundary Conditions (`top_k <= 0` and `k_constant <= 0`)
- **File:** [`app/engines/hybrid_rrf_retriever.py:75-100`](file:///d:/Claude%20Projects/regenold-eu-ai-act-rag/app/engines/hybrid_rrf_retriever.py#L75-L100)
- **Bug:** `top_k <= 0` returned 1 item instead of `[]`, and `k_constant <= 0` triggered `ZeroDivisionError`.
- **Impact:** Crashes and unexpected candidate returns under boundary inputs.
- **Suggested fix:** Return `[]` when `top_k <= 0` and raise `ValueError` if `k_constant <= 0`.
- **Confidence:** High (90%)
- **Found by:** Error Handling & Edge Cases Reviewer
- **Status:** **FIXED & VERIFIED**
