## Critical Issues

### [C1] No retry on transient Cohere failures; fail-closed guard turns one 429/5xx into a dead 110-row capture
- **File:** `app/engines/cohere_rerank.py:417` (rerank POST), `app/engines/external_embeddings.py:266` (embeddings POST), `evals/regenold/run_official_batch.py:214` (guard raise)
- **Bug:** Both clients performed exactly ONE POST per logical call; any non-200 (or exception) returned `None` immediately. The `--require-cohere` / `--require-cohere-rerank` guards then raise on the first failed call, aborting the run.
- **Impact:** Verified live: the r406 `rerank-v4.0-pro` capture died twice (`RuntimeError: Cohere rerank call failed; Cohere-required benchmark is invalid` in `docs/measurements/r405/capture-cohere.log` and `docs/measurements/r406/capture.log`). Trial keys rate-limit at 10 calls/min; a 110-row run without retry is a coin flip.
- **Suggested fix (APPLIED):** new shared helper `app/engines/_http_retry.py` — bounded exponential backoff (2/4/8 s, cap 20 s), `Retry-After` honoured and capped, only 429/5xx retried, permanent 4xx fails immediately; wired into both clients; ceilings fresh-read per call via `REGENOLD_COHERE_RERANK_RETRIES` / `REGENOLD_EXTERNAL_EMBEDDING_RETRIES` (default 3, `=1` restores one-shot). Ceilings registered in `_engine_cache_key` per the R355 doctrine.
- **Confidence:** High (reproduced twice in live logs; fixed + tripwired)
- **Found by:** Error Handling & Edge Cases + Logic & Correctness (agreed)

### [C2] Retry ceiling read at import time — env flips were inert (found by the tripwire tests, fixed before landing)
- **File:** `app/engines/cohere_rerank.py` / `app/engines/external_embeddings.py` (initial wiring)
- **Bug:** `_RETRY_ATTEMPTS = attempts_from_env(...)` ran at module import, so monkeypatched env (and same-process A/B arms) could not change behavior — and contradicted the R263.2 fresh-read convention used by every other gate in these modules.
- **Impact:** Would have made the new cache-key registrations lie (key changes, behavior cannot) and broken test-time control.
- **Suggested fix (APPLIED):** `attempts_from_env(...)` now called inside each request path, fresh per call. `tests/test_r112_perf_fixes.py::test_cohere_failure_not_cached` pins `REGENOLD_EXTERNAL_EMBEDDING_RETRIES=1` to keep isolating the negative-probe-cache concern.
- **Confidence:** High (test-driven: 6 calls instead of 2 exposed it)
- **Found by:** Contract & Integration (test contract drift) + tripwires
